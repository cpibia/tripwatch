  1. With the token, one command on the server is enough: the sensor generates a TLS key and a signing key, checks that the verifier is the right one with the CA fingerprint in the token, and writes /etc/tripwatch/bundle.json. The token is valid for one hour and once only.
  2. The bundle instead contains the private keys: it downloads once, goes to /etc/tripwatch/bundle.json owned by root with mode 600, and must be treated like a password.
